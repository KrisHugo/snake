# fixed bugs
- 游戏左上角的数值应该放在贪吃蛇的活动框之外，否则这些字样会挡住贪吃蛇。因此，应该单独放在右边一个纵向空间展示数值
- 游戏的数据中，总分并没有被保留，只留下了每一关的当前分数，因此最终总分计算是不对的。
- 游戏的数据中，时间展示是错误的，应该显示的是花费的秒数而不是timestamps总值。
- 游戏中操纵的实时性不正确，当贪吃蛇面向下方时，连按向左+向上会导致向左的运动还没有做出，贪吃蛇就直接向上转向了，这会导致贪吃蛇自己吃自己。
- 貪吃蛇邊緣保護，應該讓玩家在直直走到邊緣時留一點時間給玩家反映，而不是單純的加速后讓玩家毫無保護的衝向邊緣，如果可以重構更好的移動機制，請重構而不是在屎山代碼上重寫
- 優化預定義的變量，我希望常量是可以放在最上面預定義，但經常需要通過resetgame函數或者其他函數實時變動的變量就不用全都放在外面，避免未來繼續修改時需要同時修改兩個部分的預設值。
- ui界面和游戲界面的繪製效果應該有個區分，確保玩家能馬上分出兩個的區別，可以用html去修改
- 游戲勝利后不應該繪製下一個蘋果
- 游戲勝利時不應該用簡單的alert去暫停游戲，有點醜，而且缺乏勝利界面
- 游戲應該從開始界面選擇菜單再進入游戲正式游玩界面（以便後期修改界面）
